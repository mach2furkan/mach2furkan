## 📡 RF Signal Intelligence (SIGINT)

Gelişmiş sistemlerin kalabalık RF ortamlarında sinyalleri nasıl **tespit edip, sınıflandırıp, görselleştirdiğini** araştırıyorum.

<details>
<summary><code>$ cat focus_areas.txt</code> &nbsp;👈 tıkla, aç/kapat</summary>
<br/>

| Alan | Detay |
|---|---|
| 📶 **Spektrum izleme** | Gürültü tabanı analizi (9 kHz – 153 GHz+) |
| 🛰 **SDR hatları** | RTL-SDR · HackRF · USRP · AirSpy |
| 🔍 **Sinyal sınıflandırma** | Modülasyon tanıma, ML destekli |
| 📡 **DoA / AoA ve konumlama** | TDOA, multilaterasyon kavramları |
| 🛡 **K-İHA sensör füzyonu** | RF + Radar + EO/IR |
| ⚙ **Araçlar** | GNU Radio · Python · MATLAB · CubicSDR · SDR# |

</details>
